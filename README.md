# 📘 HTML5 e CSS3 — Curso em Vídeo

Este repositório reúne os **exercícios, desafios e projetos desenvolvidos durante o curso de HTML5 e CSS3 do Curso em Vídeo**, com foco na construção de uma base sólida em **desenvolvimento front-end**.

Os conteúdos abordam conceitos fundamentais e práticos, como:
- 🧱 Estruturação de páginas com **HTML5 semântico**
- 🎨 Estilização e layouts com **CSS3**
- 📱 Design responsivo e mobile-first
- 📐 Flexbox e CSS Grid
- 🖼️ Tipografia, cores e boas práticas de layout
- 🛠️ Organização de código e estrutura de arquivos

## 🎯 Objetivo do Repositório

Servir como **registro do aprendizado e evolução prática**, reunindo exercícios e desafios resolvidos ao longo do curso, aplicando os conceitos estudados e preparando a base para projetos mais avançados em Front-End.
